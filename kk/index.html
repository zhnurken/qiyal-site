Сұрақтар

Генерациялар бөлек төлене ме?

Иә. Qiyal провайдердің (kie.ai) өз API кілтіңізбен жұмыс істейді, генерациялар провайдерге оның бағасымен төленеді. Qiyal әр іске қосу алдында бағасын көрсетеді. Qiyal лицензиясы — тек бағдарлама.

Интерфейс қай тілдерде?

Ағылшын, орыс және қазақ тілдерінде. Тілді жоғарғы панельде кез келген уақытта ауыстыруға болады.

«Мәңгілік» пен жазылымның айырмасы неде?

«Мәңгілік» — бір реттік төлем: сатып алған кездегі Pro нұсқасы сізде мәңгі қалады, болашақ жаңартуларсыз. Жазылым — Pro және ол белсенді тұрғанда барлық жаңартулар. «Мәңгіліктен» жазылымға кез келген уақытта өтуге болады.

Жазылым біткенде не болады?

Бағдарлама Lite-қа оралады. Жобалар, сериалдар мен файлдар компьютеріңізде қалады, ал Pro жазылымды ұзартқанда қайта ашылады.

Жүйелік талаптар қандай?

Windows 10 немесе 11 (64-бит) және ЖИ-генерация мен лицензияны белсендіру үшін интернет. Монтаж, анимация және экспорт компьютеріңізде орындалады.

Жасалған контент кімге тиесілі?

Сізге. ЖИ-нәтижелерге құқық провайдер мен нақты модельдің шарттарына да байланысты.

Ақшаны қайтаруға бола ма?

Иә — сатып алғаннан кейін 14 күн ішінде. Толығырақ қайтару саясатында.

Windows «Windows компьютеріңізді қорғады» деп жазады. Бұл қауіпсіз бе?

Иә. Мұндай ескерту әлі аз жүктелген жаңа бағдарламаларда шығады. Толығырақ → Бәрібір іске қосу түймесін басыңыз. Орнатқыш біздің ресми GitHub бетімізден тікелей жүктеледі.
